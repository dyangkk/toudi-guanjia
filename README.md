# 投递管家

简历只填一次，投递全程有数。

投递管家是一款本地优先的浏览器插件（Chrome / Edge，Manifest V3）：

- **一键填表**：维护一份本机简历资料，打开招聘网站点"开始填写"，自动填写网申表单，绿色 = 已填写，橙色 = 待处理，由你最终确认提交。
- **自动记录投递**：在 Boss直聘 / 猎聘 / 智联招聘 / 前程无忧 / 牛客 / 拉勾 点击"立即沟通 / 投递简历"，自动记录公司、岗位、薪资、时间；不支持的网站可一键手动记录。
- **投递看板**：按状态（已投递 / 已查看 / 沟通中 / 面试 / Offer / 不合适）、平台、关键词筛选，查看状态时间线，写备注，一键导出 CSV。
- **隐私优先**：简历资料、API Key、投递记录全部保存在本机浏览器（`chrome.storage.local`），没有任何服务器，不上传任何数据。AI 只接收页面字段名，不接收简历具体值。

> 本项目基于开源项目 [OpenJobAutofill](https://github.com/Br1an67/OpenJobAutofill)（MIT License）二次开发，感谢原作者的开源工作。

## 安装（开发者模式）

1. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目文件夹
4. 建议把图标固定到浏览器右上角

## 使用

### 自动填写表单

1. 点击插件图标 → 「设置」→ 在「简历资料」中按模块填写信息（可导入项目自带的 `sample-profile.json` 先试用）
2. 打开任意招聘网站的简历填写页 / 网申表单页
3. 点击插件图标 → 「开始填写」
4. 检查绿色（已填）与橙色（待处理）字段，手动处理后自己点提交

AI 是可选的：不配置时使用本地规则匹配；在设置页可配置任意 OpenAI 兼容接口（如 DeepSeek），AI 只用于理解页面字段含义，不会收到你的姓名、手机号、经历内容等具体值。

### 自动记录投递

- 在支持的网站上点击「立即沟通 / 投递简历 / 立即申请」等按钮，页面右下角会提示"✅ 已记录投递"
- 同一个页面 10 分钟内重复点击不会重复记录
- 不支持的网站：打开该页面，点插件图标 → 「记录本页投递」

### 投递看板

点插件图标 → 「打开投递看板」：

- 顶部统计：总投递、今日投递、各状态数量
- 筛选：状态 / 平台 / 关键词搜索
- 每条记录：改状态（自动写入时间线）、改公司岗位信息、写备注、跳转原页面、删除
- 导出 CSV（Excel 可直接打开）

## 数据与隐私

- 所有数据仅存于本机浏览器存储，卸载插件即删除
- 更换电脑：记录暂无导出导入功能（开发中），请知悉

## 已知限制

- 各招聘网站页面结构经常变化，字段抓取是"尽力而为"，识别不准可以在看板里手动修正
- 网申官网（各公司自建 ATS）暂不自动记录，用「记录本页投递」兜底
- 文件上传类字段（`input[type=file]`）不会自动填写

## 开发

```
src/
├── manifest.json        # MV3 配置：权限、常驻站点声明
├── background.js        # 后台：消息调度、AI 代理（module）
├── tracker-core.js      # 投递记录数据层（background 专用 module）
├── tracker-content.js   # 投递事件检测（常驻招聘站点）
├── content.js           # 表单扫描与填写（按需注入）
├── popup.html/js        # 弹窗：开始填写 / 记录本页 / 看板入口
├── dashboard.html/js    # 投递看板
└── options.html/js      # 设置：简历资料 + AI 配置
```

无构建步骤，改完代码到扩展管理页点「重新加载」即可。
